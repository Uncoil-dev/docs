# Uncoil docs

The public documentation for [Uncoil](https://www.uncoil.dev/docs): quickstart, SDK guides, API reference, and self-hosting.

Each page is a Markdoc file (`.mdoc`). The website repo [Uncoil-dev/Uncoil](https://github.com/Uncoil-dev/Uncoil) mounts this repo at `content/docs` and renders it at `/docs`.

## Edit a page

1. Edit the `.mdoc` file. Keep the frontmatter (`title`, `description`, `section`, `order`).
2. Open a pull request.
3. After it merges, the website repo updates its pointer to this repo, then the site is deployed.
